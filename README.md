Predictive Analytics &amp; Machine Learning for Managers (PAML4M) - companion site for my book with the same name. If you find these free scripts useful, please consider recommending the book to your colleagues and buying the conceptual book  (https://www.amazon.com/dp/B0C2RX8NY1). The ePub version is inexpensive.

This repository contains knitted PDF files with R scripts written in Quarto, with the necessary explanations and hands-on examples related to the concepts covered in the PAML4M book. The files are provided in three formats: .Qmd Quarto and knitted PDF and ePub formats. This repository is intended to be a companion for the book, but anyone with experience with predictive analytics and machine learning concepts can use this R code independently. That is, the book is not required to follow the code, it just complements it. However, the book is self-published and inexpensive and it is very useful for managers interested in conceptual foundation about how to select, specify, develop, test and interpret models.
